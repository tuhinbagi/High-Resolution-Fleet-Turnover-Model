# High-Resolution Fleet Turnover Model (HRFTOM)

Code for: Bagi, T. A., Hennesey, E., & Syal, S. M. *High-Resolution Fleet Turnover Model to Assess California's Electric Vehicle Transition.* iScience (2026). DOI: [to be added]

The model projects the light-duty vehicle fleet of every California ZIP code from a 2019 baseline to 2050. It splits each fleet into EVs and internal combustion vehicles (ICE).

## How it works

For each ZIP code and each output year (2020, 2025, …, 2050), the model:
1. Starts from the 2019 fleet, broken down by model year and fuel type.
2. Adds new vehicle sales for every year from 2020 up to the output year. Sales grow with county-level EMFAC sales changes and are split into EV and ICE using the EV-share forecast.
3. Retires vehicles using a survival curve. Vehicles already in the 2019 fleet use conditional Kaplan–Meier survival. New sales, and all vehicles under the NHTSA curve, use unconditional survival.
4. Records the EV count, ICE count, EV share, and average fleet age.

## Data

The data files are not included in this repository. They are built from these public sources:

| Source | Used for |
|---|---|
| [CARB EMFAC Fleet Database](https://arb.ca.gov/emfac/fleet-db) | Vehicle registrations by ZIP code, model year and fuel type (2015–2019); county vehicle sales |
| [U.S. Census Bureau, 2019 American Community Survey 5-Year Estimates](https://data.census.gov) | Median household income, population, and race/ethnicity by ZIP code |
| NHTSA vehicle survival schedule (reference [41] in the paper) | NHTSA survival curve |

## Run

```bash
Rscript -e 'rmarkdown::render("Vehicle_Retirement_Kaplan_Meier.Rmd")'   # 1. survival curves
Rscript -e 'rmarkdown::render("EV_Sales_Logistic_Growth.Rmd")'          # 2. EV sales forecasts
python run_all_scenarios.py                                            # 3. fleet model
jupyter notebook Plots.ipynb                                           # 4. figures (Run All)
```

R packages: `dplyr`, `tidyr`, `survival`, `rmarkdown`.

`run_all_scenarios.py` runs six configurations: three survival curves (`zipcode`, `california`, `nhsta`) times two EV scenarios (`BAU`, `ACCII`, i.e. Advanced Clean Cars II). Results are written to `results_conditional/`:
- `fleet_summary_<survival>_<scenario>.csv` has one row per ZIP code and year, with EV count, ICE count, EV share, and average fleet age.
- `fleet_details_<survival>_<scenario>.csv` has surviving vehicles by model year and fuel type.

Figures are saved to `plots_conditional/`.

To run a single configuration:

```python
from High_Resolution_Fleet_Turnover_Model import main
summary, details = main(survival_mode="zipcode", ev_scenario="ACCII")
```
